# Gudrais pirkumu saraksts

Vienkāršs Python un Streamlit prototips.

## Kā palaist programmu

1. Atver failu app.py VS Code.
2. Atver termināli.
3. Instalē Streamlit:

   `python -m pip install streamlit`

4. Palaid programmu:

   `python -m streamlit run app.py`

5. Atver pārlūkprogrammā adresi, kas parādās terminālī. Parasti tā ir http://localhost:8501.

## Ko programma prot

- Pievienot produktus pirkumu sarakstam.
- Pievienot savus produktus.
- Izvēlēties veikalu: Rimi, Maxima vai Lidl.
- Sakārtot produktus pēc izvēlētā veikala nodaļu secības.
- Atzīmēt nopirktos produktus.
- Aprēķināt aptuveno pirkumu summu.

## Svarīgi

Produktu cenas un veikalu nodaļu secība ir tikai piemēri. Tās nav īstās veikalu cenas vai precīzi veikalu plāni.
